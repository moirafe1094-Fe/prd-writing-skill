# Regression Scenario: Mixed PC And APP Attachments

## Input

Write and publish a PRD covering a PC configuration workflow and an APP execution workflow.

## Required Result

- Produce one PC-only self-contained HTML and one APP-only self-contained HTML.
- Upload both as real Feishu attachments.
- Render the prototype attachment area as two columns: PC left, APP right.
- The PC file contains no APP screens or walkthrough; the APP file contains no PC screens.
- A single combined HTML, stacked APP-above-PC layout, filename placeholder, or raw attachment link fails the scenario.

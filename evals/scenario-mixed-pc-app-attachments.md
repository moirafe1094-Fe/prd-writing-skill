# Regression Scenario: Mixed PC And APP Prototypes

## Input

Write and publish a PRD covering a PC configuration workflow and an APP execution workflow, with HTML prototypes for both.

## Required Result

- Produce one PC-only self-contained HTML and one APP-only self-contained HTML.
- Embed each as an HTML component block (`html5-block`) under 3.4（1）原型图与功能布局.
- Order: PC group (title → block → PC page descriptions), then APP group (title → block → APP page descriptions).
- The PC file contains no APP screens; the APP file contains no PC screens.
- A file attachment card instead of a component block, a single combined HTML, component blocks inside grid columns, descriptions placed before the block, screenshots of the embedded HTML, or a blank strip under a block caused by scaling `html` / `body` fail the scenario.

# Regression Scenario: Per-Page Screenshot Layout (No HTML)

## Input

Publish a PRD with three PC pages and three APP pages/states. Only screenshots are available; there is no HTML prototype.

## Required Result

- All six Requirement Description page units have a matching screenshot.
- Each PC unit is ordered heading → screenshot → description.
- Each APP unit is one two-column block with screenshot left and description right.
- One overview screenshot for multiple pages, a screenshot gallery, a missing screenshot placeholder, or APP screenshot above description fails the scenario.
- If an HTML prototype is later provided, the screenshots are replaced by HTML component blocks (see `scenario-mixed-pc-app-attachments.md`).

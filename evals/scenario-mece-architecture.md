# Regression Scenario: MECE Questions And Architecture Diagram

## Input

Clarify and publish a medium requirement with two input sources, a calculation/merge rule, PC management, APP execution, and downstream audit.

## Required Result

- Brainstorming tracks the eight MECE domains and asks each unresolved decision once.
- Choices within each question do not overlap and cover “不涉及/保持现状” or “暂不确定” where valid.
- The requirement is classified as medium before artifact creation.
- The PRD contains both a business flowchart and a separate business architecture whiteboard.
- The architecture shows sources, rule/import paths, aggregation, core capability, downstream result, and exceptional bypass boundaries.
- A flowchart relabeled as “架构图”, a generic frontend/backend/database stack, or a screenshot/raw code block fails the scenario.

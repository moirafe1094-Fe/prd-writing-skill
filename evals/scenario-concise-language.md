# Regression Scenario: Concise PRD Language

## Input

Write a PRD from an HTML prototype and screenshots.

## Failure Pattern

The draft adds paragraphs explaining that the PRD uses the HTML as a visual reference, that screenshots are arranged from overview to detail, and that this helps reviewers confirm the layout and controls.

## Required Result

- Attach the prototype and place each screenshot with its requirement without narrating that document arrangement.
- Keep a source-of-truth sentence only when ambiguity would otherwise exist, and limit it to one direct sentence.
- Removing any remaining meta sentence must change a requirement, decision, or acceptance meaning; otherwise the sentence is deleted.
